## 1. Hackathon Overview & Theme

#### Main description

On-device models are fast, private and free to run, but they aren't on every device. #BuildHybridAI challenges you to build apps that use both. Using the Firebase AI Logic Hybrid Inference SDK, your app runs prompts on-device when a local model is available and falls back to the cloud when it isn't.

Build for at least one platform: Web (Chrome) or Android with Gemini Nano 4, or iOS with Apple Foundation Models, all through Firebase AI Logic. Want to go further? Apps that run across multiple platforms will be given strong consideration for the Grand Prize, since that's where a single hybrid SDK really shines. An outstanding single-platform app can still win. For example: a notes app that summarizes on-device offline and hands long documents to the cloud. New projects and significantly updated existing apps are both eligible, and the competition is open to individuals, teams and organizations in most countries (see the [Official Rules](https://firebasehybridaihackathon.devpost.com/rules)).

#### Why join?

* $30,000 in cash prizes, including a $10,000 Grand Prize and a $3,000 award for the best app on each platform
* Top winners get an interview and a featured blog post from the Firebase team
* Learn hybrid inference: one SDK for on-device and cloud AI across Web, Android and iOS
* Bring an existing app — it's eligible if significantly updated during the competition
* Start free: text inference with Firebase AI Logic is free within usage limits, and you can request a Google Account Quota for advanced features such as image generation

## 2. Requirements & Submission Guidelines

### Requirements

#### Requirements

##### What to Build

Build a Gen AI application using Firebase AI Logic along with supported firebase products such as: AppCheck, RemoteConfig, Firestore and Authentication.

*Build for one of these platforms:*

* Web (Chrome): Gemini Nano 4 via Firebase AI Logic. Build a web app or a Chrome extension.
* Android: Gemini Nano 4 via Firebase AI Logic.
* iOS: the [Apple Foundation Models](https://firebase.google.com/docs/ai-logic/apple-foundation-models-framework/get-started?api=dev) API for local execution via Firebase AI Logic.

Firebase AI Logic requires App Check; debug tokens are accepted in submissions. You're encouraged to use other Firebase products, such as Remote Config, Firestore and Authentication.

##### How to Build

Build with any AI coding tool or IDE you like, such as Antigravity, Android Studio, Claude Code, Codex or Cursor, as long as your app's AI runs on Firebase AI Logic. Google tools like Antigravity are recommended. Coding agents work best with [Firebase Agent Skills](https://firebase.google.com/docs/ai-assistance/agent-skills), which come built into Antigravity and Android Studio.
